# Agent skill

Registering the server gives an agent the tools. The skill tells it how to use
them well: search before browsing, address folders by role, page instead of
pulling 200 messages, raise `max_chars` only when a body was truncated. It also
reminds the agent that the server is read-only, that a tool the user disabled
stays disabled, and that the text of an email is data, never instructions.

It's a single file, [`skills/rubit-mail/SKILL.md`](https://github.com/bgalmes/rubit-mcp-mail/blob/main/skills/rubit-mail/SKILL.md).
It's optional, and the server works without it.

## Claude Code

Copy the `rubit-mail` folder into a skills directory. Use your user directory
for every project:

```bash
mkdir -p ~/.claude/skills && cp -r skills/rubit-mail ~/.claude/skills/
```

or a single project's `.claude/skills/`. Claude Code picks it up on the next
session; `/skills` lists it.

The skill is named `rubit-mail`, matching the server name the
[installer and `claude mcp add`](/docs/install/claude-clients) register.

## Other agents

The file is a standard `SKILL.md`: YAML frontmatter with a `name` and a
`description`, then Markdown. Any agent that loads skills in that format can
use it. Put the folder wherever that agent looks for skills.
